# SAGE 流程图

## 1. 完整流程

```
用户查询
    │
    ↓
┌───────────────────┐
│  时效性检测 (LLM) │
└───────────────────┘
    │
    ├─ TEMPORAL → 跳过缓存
    └─ STATIC → 继续
    │
    ↓
┌───────────────────┐
│  图匹配 (LLM)     │
└───────────────────┘
    │
    ├─ 匹配成功 → 实例化 plan + 复用依赖
    └─ 匹配失败 → 生成新 plan
    │
    ↓
┌───────────────────┐
│  智能剪枝         │
├───────────────────┤
│ Stage 1 (快速)    │
│ Stage 2 (深度)    │
└───────────────────┘
    │
    ↓
┌───────────────────┐
│  依赖检查         │
│  (连带剪枝)       │
└───────────────────┘
    │
    ↓
┌───────────────────┐
│  执行剪枝后的 plan│
│  (并行 + 推测)    │
└───────────────────┘
    │
    ↓
┌───────────────────┐
│  综合结果         │
└───────────────────┘
```

## 2. 剪枝流程

```
输入: plan = [hop1, hop2, hop3, hop4]
    │
    ↓
┌─────────────────────────────┐
│  Stage 1: 逐个快速判断      │
└─────────────────────────────┘
    │
    ├─ hop1: EXECUTE (第一个)
    ├─ hop2: EXECUTE (明确重要)
    ├─ hop3: UNCERTAIN (不确定) ← 进入 Stage 2
    └─ hop4: EXECUTE (明确重要)
    │
    ↓
┌─────────────────────────────┐
│  Stage 2: 深度评分          │
├─────────────────────────────┤
│  输入: [hop3]               │
│  LLM 生成:                  │
│    - Speculation            │
│    - hop3 importance: 72    │
│  决策: 72 ≥ 60 → 保留       │
│  缓存: speculation_cache    │
└─────────────────────────────┘
    │
    ↓
┌─────────────────────────────┐
│  依赖检查                   │
│  (检查是否需要连带剪枝)     │
└─────────────────────────────┘
    │
    ↓
输出: plan = [hop1, hop2, hop3, hop4]
```

## 3. 执行流程

```
hop3 执行:
    │
    ↓
┌─────────────────────────────┐
│  检查 speculation 缓存      │
└─────────────────────────────┘
    │
    ├─ 有缓存 → cached_spec (0ms)
    └─ 无缓存 → 生成新 spec (150ms)
    │
    ↓
┌─────────────────────────────┐
│  并行执行                   │
├─────────────────────────────┤
│  API (300ms)                │
│    ║                        │
│  Speculation (0ms/150ms)    │
└─────────────────────────────┘
    │
    ↓
┌─────────────────────────────┐
│  Judge 验证                 │
│  score = verify(api, spec)  │
└─────────────────────────────┘
    │
    ├─ score ≥ 75 → 使用 spec
    └─ score < 75 → 使用 API + reasoning
    │
    ↓
返回结果
```

## 4. 图匹配流程

```
新查询: "Medusa 的性能"
    │
    ↓
┌─────────────────────────────┐
│  遍历 graph_db              │
└─────────────────────────────┘
    │
    ↓
┌─────────────────────────────┐
│  Layer 1: Query 匹配 (LLM) │
├─────────────────────────────┤
│  找到候选图:                │
│  "analyze_{ENTITY}_perf"    │
│  提取映射:                  │
│  {ENTITY} → "Medusa"        │
└─────────────────────────────┘
    │
    ↓
┌─────────────────────────────┐
│  Layer 2: Structure 匹配    │
├─────────────────────────────┤
│  比较抽象结构               │
│  相似度 > 0.7 → 匹配成功    │
└─────────────────────────────┘
    │
    ↓
┌─────────────────────────────┐
│  Layer 3: Hop 匹配          │
├─────────────────────────────┤
│  逐个匹配 hop               │
│  建立映射关系               │
└─────────────────────────────┘
    │
    ↓
┌─────────────────────────────┐
│  实例化                     │
├─────────────────────────────┤
│  1. 替换实体占位符          │
│  2. 复用依赖关系            │
│  3. 生成新 plan             │
└─────────────────────────────┘
```

## 5. 依赖检查流程

```
初始剪枝: skip_set = {hop2}
    │
    ↓
┌─────────────────────────────┐
│  检查所有未剪枝的 hops      │
└─────────────────────────────┘
    │
    ↓
对 hop4:
  │
  ├─ 依赖: hop4 → hop2 (data, 0.85)
  ├─ hop2 被剪枝? YES
  ├─ 依赖强度 > 0.7? YES
  └─ 决策: 连带剪枝 hop4
    │
    ↓
更新: skip_set = {hop2, hop4}
    │
    ↓
重复检查 (迭代直至收敛)
    │
    ↓
最终: skip_set = {hop2, hop4}
```

## 6. Speculation 复用流程

```
┌─────────────────────────────┐
│  Stage 2 剪枝               │
└─────────────────────────────┘
    │
    ├─ 生成 speculation (150ms)
    ├─ 评估 hop 重要性
    └─ 缓存 speculation
    │
    ↓
speculation_cache = {
    "hop3": "EAGLE 约 2.5x...",
    "hop4": "常见问题..."
}
    │
    ↓
┌─────────────────────────────┐
│  执行阶段                   │
└─────────────────────────────┘
    │
    ↓
执行 hop3:
  │
  ├─ 检查缓存: 存在 ✓
  ├─ API ║ 缓存的 spec (0ms)
  ├─ Judge 验证
  └─ 使用 or 不使用
    │
    ↓
节省: 150ms GPU + 200 tokens (如果通过验证)
```

## 7. 数据流

```
查询: "分析 EAGLE 的部署挑战"
    │
    ↓
[时效性] LLM → STATIC
    │
    ↓
[图匹配] LLM → 找到 "analyze_deployment"
    ↓
    Entity: {ENTITY} → "EAGLE"
    │
    ↓
[实例化]
    plan: [hop1, hop2, hop3, hop4]
    dependencies: {
        "hop3": [("hop1", "semantic", 0.5)],
        "hop4": [("hop2", "data", 0.85)]
    }
    │
    ↓
[Stage 1] LLM × 4
    hop1: EXECUTE
    hop2: EXECUTE
    hop3: UNCERTAIN
    hop4: EXECUTE
    │
    ↓
[Stage 2] LLM × 1
    hop3 importance: 72 → 保留
    speculation_cache["hop3"] = "..."
    │
    ↓
[依赖检查]
    无连带剪枝
    │
    ↓
[执行]
    hop1: API ║ 新 spec → Judge → spec ✓
    hop2: API ║ 新 spec → Judge → API ✓
    hop3: API ║ 缓存 spec → Judge → 缓存 spec ✓ (节省 150ms)
    hop4: API ║ 新 spec → Judge → spec ✓
    │
    ↓
[综合]
    最终答案
```
